# Ferrous Lion

Official landing page for [Ferrous Lion](https://x.com/FerrousLion) — streams, clips, and the games on rotation.

- Live: Twitch, YouTube, TikTok, X
- Latest YouTube videos load automatically
- Epic creator code: `ferrouslion`

## Local

```bash
npm install
npm run dev
```

## Deploy

This is a TanStack Start app. Point Vercel (or similar) at this repo and it will build with `npm run build`.
